# hello-springboot

## 프로젝트 개요
이 프로젝트는 개인 학습을 목적으로,
Spring Boot 기반의 프로젝트 구조를 다시 정리해보고
개발 감각을 유지하기 위해 진행했습니다.

기능 구현보다는
프로젝트 생성부터 실행, 설정 관리,
CI 구성까지의 전체 흐름을 직접 다시 구성해보는 데 의미를 두었습니다.

## 기술 스택
- Java
- Spring Boot
- Maven
- H2 (로컬)
- MySQL (배포 환경)
- GitHub Actions (CI)

## 구성 및 구현 내용
- Spring Boot 기본 프로젝트 생성 및 설정 구성
- application.yml 기반 환경 설정 관리
- 간단한 API 작성
- GitHub Actions를 이용한 CI 설정

## 진행하며 신경 쓴 점
- 기능을 많이 추가하기보다는
  프로젝트 구조와 설정 흐름을 이해하는 데 집중했습니다.
- 에러가 발생했을 경우
  로그와 설정을 기준으로 원인을 확인하며 수정했습니다.
- DB 접속 정보는 환경 변수로 분리하여 관리하도록 구성했습니다.

## 정리
실무 수준의 복잡한 기능을 구현한 프로젝트는 아니지만,
Spring Boot 기반의 프로젝트 구성과 실행 흐름을 다시 정리하고
개발 감각을 유지하는 데 목적을 둔 학습용 프로젝트입니다.
